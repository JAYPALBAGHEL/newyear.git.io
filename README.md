# PayrollPro India (PHP)

A lightweight PHP payroll calculator for Indian salary processing.

## Features
- Input employee compensation details
- Calculates gross salary
- Computes PF, ESI, professional tax, and TDS estimate
- Displays net salary with a payslip-style summary

## Run locally
```bash
php -S 0.0.0.0:8000
```
Then open `http://localhost:8000`.

> Note: This is a simplified payroll demo and not a legal/tax compliance engine.
